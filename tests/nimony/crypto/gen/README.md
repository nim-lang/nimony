# Test-vector generators

These scripts made the committed vectors and keys of `tests/nimony/crypto`.
The test suite does not run them; they are kept as the provenance of the
data. Each one is deterministic for the inputs named below, so running it
again should leave `git status` clean.

Dependencies: Python 3.9 or later, the Python `cryptography` package (46 was
used; it is OpenSSL-backed) and the `openssl` command line tool (3.5.9 was
used). `badkeys.py` needs only the Python standard library.

| Script | Reads | Writes |
|---|---|---|
| `ctbignum_vectors.py KEYDIR` | `KEYDIR/2048a.pem`, `3072.pem`, `4096.pem` | the vector constants of `tctbignum.nim` (from `# generated by ctbignum_vectors.py` to the end of `CrtKeys`), on stdout |
| `ctbignum_keys.py ../tctbignum.nim KEYDIR` | `CrtKeys` in `tctbignum.nim` | those three keys as PEM, for `ctbignum_vectors.py` |
| `rsasign_vectors.py WYCHEPROOF_DIR NIST_DIR KEYDIR OUTDIR` | Wycheproof's `rsa_pkcs1_*_sig_gen_test.json` and `rsa_signature_*_sha256_test.json`, NIST CAVP's `SigGen15_186-3.txt`, the keys in `rsakeys/` | `rsavectors/wycheproof_siggen.txt`, `nist_siggen15.txt`, `wycheproof_messages.txt` and `openssl.txt` (signatures from `openssl dgst -sign`) |
| `badkeys.py ../rsakeys` | `rsakeys/test2048.pkcs1.der` | `rsakeys/bad/*.der`, each breaking one rule of `parseRsaPrivateKeyDer` |

Run them with `python3 -P` so that nothing in the current directory is
imported. The source URLs and licences of the Wycheproof and NIST files are
in the header of `rsasign_vectors.py` and of each file it writes.

## The other keys in `rsakeys/`

All are throwaway test keys made with OpenSSL 3.5.9 for this suite; each PEM
file says so in its first lines. They were made by hand, not by a script:

- `testBITS.pkcs8.pem` and `test2048b.pkcs8.pem`:
  `openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:BITS`.
  The `.pkcs1.pem` files are the same keys through `openssl pkey -traditional`;
  the `.der` files are the base64 bodies of the PEM files of the same name.
- `testBITS.hello.sig`: `openssl dgst -sha256 -sign testBITS.pkcs8.pem` of the
  message `hello nimony` (`Hello` in `trsakey.nim`).
- `test1024.*`: as above with 1024 bits, which the parser must refuse.
- `test2048.encrypted.pem`: `openssl pkcs8 -topk8` of test2048 (PBES2,
  AES-256-CBC); `test2048.pkcs1-encrypted.pem`: `openssl rsa -aes128
  -traditional` (a `Proc-Type: 4,ENCRYPTED` header). Both must be refused,
  so the password does not matter.
- `ecp256.pkcs8.pem`: `openssl genpkey -algorithm EC -pkeyopt
  ec_paramgen_curve:P-256`.
- `testpss2048.pkcs8.pem`: `openssl genpkey -algorithm RSA-PSS -pkeyopt
  rsa_keygen_bits:2048` (an `id-RSASSA-PSS` key, refused as not
  `rsaEncryption`).
- `bad/multiprime.pkcs8.pem`: `openssl genpkey -algorithm RSA -pkeyopt
  rsa_keygen_bits:2048 -pkeyopt rsa_keygen_primes:3`; `multiprime.pkcs1.pem`
  is the same key through `openssl pkey -traditional`.
